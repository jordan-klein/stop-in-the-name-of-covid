# Stop, in the Name of COVID!
This repo provides the data and scripts for facilitating the reproduceability of the following paper:

Jordan D. Klein, Ingmar Weber, Emilio Zagheni; Stop, in the Name of COVID! Using Social Media Data to Estimate the Effects of COVID-19-Related Travel Restrictions on Migration. Demography 1 April 2024; 61 (2): 493–511. doi: https://doi.org/10.1215/00703370-11229946
